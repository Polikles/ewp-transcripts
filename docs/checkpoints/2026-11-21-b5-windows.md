## Audit and changes

- Native CPython 3.12 Win x64 TorchCodec 0.7 wheel exists; upstream v0.7 release documents beta
  Windows support with torch 2.8. WhisperX 3.8.6 dependency markers support native Windows and
  limit Triton to Linux. ML/model pins are unchanged. uv resolves Linux x86_64 and Windows AMD64
  in one lock; only colorama/tzdata are added for Windows, existing dependency versions retained.
- Replace eager fcntl import with platform-specific native descriptor locking. Guard POSIX
  descriptor modes throughout resumable/consent storage; Windows inherits directory ACLs.
- Workdir ownership checks on Windows query process exit state with correctly typed 64-bit
  handles. Never use os.kill(pid, 0), whose Windows semantics can terminate the target.
- Windows drive inputs remain native; WSL drive normalization stays. Windows system roots and
  junctions are rejected by GUI validation. Native desktop directory picker uses PowerShell.
- Private Windows FFmpeg shared build and Torch CUDA DLL paths are process-local. Doctor
  identifies native Windows without misleading missing-WSL/Ubuntu warnings; repair guidance
  and bundled native setup help are available in GUI. Heavy ML imports remain lazy.
- PowerShell repository setup/repair explicitly installs Python 3.12/locked dependencies and
  FFmpeg 7.1.1 shared under LOCALAPPDATA, without replacing system FFmpeg/PATH or downloading
  models by default. Runtime failures fail setup; missing pinned models remain explicit.
- Separate cross-platform model preparation is opt-in, uses configured immutable revisions and
  private gated-token prompt. Normal transcription never downloads models.
