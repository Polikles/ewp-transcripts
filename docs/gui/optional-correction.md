# Optional correction

Use this guide with the matching stage in EwP Transcripts. Interface language does not change recording or translation language.

1. Choose recording: Open a completed recording from the queue. Batch checkboxes select independent recordings for batch actions.
2. Choose provider and dictionary: For assistance, choose the exact provider, model and optional dictionary. Check readiness and read the disclosure.
3. Generate correction candidate: Give scoped consent and Generate correction candidate. Suggestions remain non-final.
4. Continue to source review: Open the candidate in manual review, or Skip LLM-assisted correction to review the original ASR text.

## Detailed instructions

This stage is optional. Source review and subtitle export work without an API, LLM or dictionary. Skip only records that this optional stage is not being used; it does not verify the transcript.

Local and cloud providers are separately operated. Keys stay in server memory. Nothing is sent merely by choosing a recording or provider. Consent applies to the displayed provider and source.

For batch work, select recordings explicitly, then use the batch generation or skip action. Review each result and error separately. A correction candidate never changes the canonical ASR file or publishes a verified revision.

## Next step

Return to the application and use the numbered sections and actions above. Saving a draft is separate from human approval and immutable publication.
