# Dictionaries

Use this guide with the matching stage in EwP Transcripts. Interface language does not change recording or translation language.

1. Choose project inputs: Choose canonical and exact verified revision directories, project ID and output root.
2. Generate proposal: Generate proposal compares source and reviewed text without calling an LLM.
3. Review every decision: Accept, reject or edit candidates using their context; Save decisions.
4. Publish dictionary: Choose a new dictionary ID, confirm review and Publish project dictionary.

## Detailed instructions

Dictionaries are auxiliary tools, not a mandatory stage of transcription, review, translation or export. Existing correction dictionaries can be selected in optional provider stages. Keep project/language/version/hash identity explicit.

Use exact canonical/manual-revision pairs and preserve rejected decisions as well as accepted entries. Publication is immutable and requires every candidate to be resolved. Translation dictionaries and source-language correction dictionaries remain conceptually separate; this manager does not silently create a translation dictionary or rewrite canonical transcripts.

## Next step
