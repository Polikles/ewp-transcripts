# Słowniki

Używaj poniższych kroków razem z odpowiadającym im etapem GUI.

1. Wybierz bibliotekę słowników: Odśwież katalog, dodaj plik, utwórz pusty słownik lub wczytaj przykład. Usunięte z listy pozycje można przywrócić.
2. Wyświetl i porównaj wersje: Otwórz wersję do przeglądu i edycji. Wybierz drugą wersję i porównaj terminy, zakres i konwencje.
3. Edytuj nową wersję: Edytuj projekt, zakres i wpisy, zachowując decyzje. Pełny JSON udostępnia konwencje ręczne. Przy edycji użyj nowego ID.
4. Zapisz nową wersję słownika: Zapisz nową niezmienną wersję. Usunięcie z listy ukrywa wpis, zachowując pliki wcześniejszych zadań. Propozycje z nagrań są dostępne poniżej.

## 1. Wybierz bibliotekę słowników

Słowniki są opcjonalne. Lista odświeża się automatycznie przy uruchomieniu interfejsu; odświeżenie ręczne przydaje się po zmianach poza programem. Wybierz katalog biblioteki, dodaj JSON, utwórz pusty słownik albo wczytaj edytowalny przykład. Wybierz rodzaj: korekta terminów języka źródłowego albo tłumaczenie w określonym kierunku.

## 2. Wyświetl i porównaj wersje

Otwórz wybraną wersję do przeglądu i edycji. Wybierz drugą i porównaj wpisy, zakres projektu i konwencje. Wersje rozróżnia ID słownika i hash treści; wersja schematu JSON nie jest numerem wydania słownika. Pokaż usunięte słowniki pozwala przywrócić pozycje ukryte z listy.

## 3. Edytuj nową wersję

Edytuj projekt, język lub kierunek, terminy i decyzje. Pełny JSON udostępnia też konwencje ręczne. Zachowuj wpisy zatwierdzone i odrzucone; odrzucone mapowania nie mogą być wysyłane jako zatwierdzone instrukcje dostawcy. Słownik jest kontekstem projektu, a nie uniwersalnym korektorem. Przy zmianie treści nadaj nowy ID słownika. Wcześniejsze słowniki i canonical JSON pozostają niezmienione.

Niżej dostępna opcjonalna propozycja z nagrań porównuje dokładne pary canonical JSON i ręcznej rewizji. Przed publikacją sprawdź i zatwierdź albo odrzuć każde mapowanie. Poprzedni słownik może przenieść oba rodzaje decyzji. Ta zaawansowana ścieżka nie jest potrzebna do stworzenia małego słownika ręcznego.

## 4. Zapisz nową wersję słownika

Zapisz nową wersję słownika publikuje niezmienną wersję. Powtórzony ID, powtórzone terminy źródłowe lub nieaktualna baza edycji powodują błąd zamiast cichego nadpisania. Następnie wybierz dokładnie tę wersję w korekcie lub tłumaczeniu. Usuń z listy ukrywa pozycję bez kasowania plików wcześniejszych zadań i pozwala ją przywrócić.

## Import, eksport i kopie zapasowe

Eksportuj słownik pobiera oryginalny JSON niezależnie od profilu użytkownika. Dodanie pliku waliduje importowaną wersję i zachowuje jej bajty, tożsamość i pochodzenie. Ponowne dodanie identycznej treści jest bezpieczne. Inna treść z tym samym ID nie nadpisze wersji; zamiast tego edytuj i zapisz pod nowym ID. Kopiuj katalog biblioteki lub eksportuj potrzebne wersje. Profil użytkownika może opcjonalnie zawierać pliki słowników, ale niezależny import i eksport pozostają dostępne.
