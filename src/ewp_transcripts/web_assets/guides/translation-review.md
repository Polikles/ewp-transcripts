# Translation review & export

Use this guide with the matching stage in EwP Transcripts. Interface language does not change recording or translation language.

1. Choose recording: Open the recording’s manual translation or saved candidate from its queue. Check source and direction.
2. Review source and target: Compare every source unit with the target and correct meaning, names, omissions and additions.
3. Preview translation: Save the translation draft, then Preview translation. Resolve errors and review warnings.
4. Apply verified translation: Confirm manual semantic verification and Apply verified translation.
5. Audit and export: Choose formats and Audit and export verified translation. Proceed with next output returns to the queue.

## Detailed instructions

The source text and ownership are immutable. Review the editable target in context; provider output is not evidence of correctness. Check direction and the exact source revision, especially when a newer verified source is available.

Empty targets are rejected by default. Only enable Allow empty translation units when intentionally omitting a unit, then Preview again. Omission provenance is retained and omitted units are excluded from exported text/captions. Verification and omission confirmation are not restored from a saved workspace.

Apply publishes an immutable manual child. Exports use the approved translation and support TXT, SRT, VTT and HTML. Existing artifacts remain intact. Source-language YTT is handled in Source review & export; this stage does not add a translated YTT renderer.

## Next step

Return to the application and use the numbered sections and actions above. Saving a draft is separate from human approval and immutable publication.

Queue legends sit below the queue. Clear current translation review is a secondary action below Preview and affects the current browser view; saved files remain available. Hover over Apply and Audit/export for their verification and lineage requirements.
