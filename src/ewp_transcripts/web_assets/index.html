How to use this page
  1. Enter one allowed input file and a shared output directory.
  2. Inspect it, then run and review dry-run.
  3. Confirm the exact plan and add the file to the staged queue.
  4. Repeat with files from any allowed root, keeping the same output directory.
  5. Review the table, remove mistakes, then start the queue.
